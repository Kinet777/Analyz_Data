# План реализации: Пайплайн Видеоаналитики (Курсовая работа)

Этот документ описывает архитектуру и план реализации системы комплексного анализа видео (ПЗ 1 - ПЗ 8), объединяющей компьютерное зрение, распознавание речи, OCR и большие языковые модели. В качестве прикладной задачи выбрано **выявление деструктивного контента** (оружие, агрессия, нецензурная лексика, опасные сцены).

## 1. Архитектура решения

Решение будет представлять собой модульное Python-приложение. Главный скрипт (`main.py`) будет оркестрировать работу независимых анализаторов.

### Пайплайн обработки (Сценарий)
1. **Загрузка и подготовка (ПЗ 1, ПЗ 2):** Загрузка видео по URL (yt-dlp), извлечение аудиодорожки (ffmpeg) и нарезка видео на кадры с заданной частотой (OpenCV).
2. **Анализ аудио (ПЗ 4):** Транскрибация аудио в текст с помощью модели **Whisper**. Поиск триггерных слов.
3. **Распознавание текста на кадрах (ПЗ 3):** Использование **EasyOCR** для чтения вшитых субтитров и текста на экране.
4. **Детектирование объектов (ПЗ 5):** Использование **YOLOv8** для поиска конкретных объектов (например, люди, машины, оружие - в зависимости от датасета, используем базовую модель COCO).
5. **Классификация сцен (ПЗ 6):** Использование **ResNet50** (PyTorch) для общей классификации кадра (что происходит в целом).
6. **Глубокий анализ с помощью LLM (ПЗ 7):** Передача ключевых кадров в **Gemini API** с промптом на выявление подозрительного или деструктивного поведения, которое сложно описать обычными классификаторами.
7. **Постобработка и агрегация (ПЗ 8):** 
   - *Текст:* Дедубликация одинакового текста, распознанного на соседних кадрах.
   - *Объекты:* Склейка срабатываний YOLO (трекинг или сглаживание детекций во времени).
   - *Агрегация:* Формирование итогового отчета (JSON + Markdown), где по таймкодам расписаны все найденные объекты, текст и транскрипция.

## 2. Структура проекта

Будут созданы следующие файлы:
- `main.py` — Точка входа, оркестратор.
- `video_utils.py` — Загрузка, нарезка кадров, извлечение звука (на базе ваших ПЗ 1 и 2).
- `audio_analyzer.py` — Интеграция с Whisper.
- `vision_analyzer.py` — Интеграция YOLO, ResNet и EasyOCR.
- `llm_analyzer.py` — Интеграция с Gemini API.
- `postprocessor.py` — Дедубликация и склейка результатов.
- `requirements.txt` — Список зависимостей.
- `README.md` — Инструкция по запуску, деплою на Timeweb и загрузке на GitHub.
