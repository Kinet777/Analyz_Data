# Готово: Пайплайн Видеоаналитики (Курсовая работа)

Я завершил реализацию всего программного комплекса для вашей курсовой работы. Все модули написаны, объединены в единый сценарий и готовы к работе.

## Что было сделано

1. **Создана единая архитектура:**
   - Основана на ваших наработках (ПЗ 1 и ПЗ 2), которые я обернул в удобные функции в `video_utils.py`.
   - Написаны независимые модули-анализаторы, чтобы пайплайн был расширяемым и чистым.

2. **Интеграция всех моделей:**
   - **`audio_analyzer.py` (ПЗ 4):** Интеграция `openai-whisper` для перевода аудиодорожки видео в текст. Добавлен поиск триггерных/деструктивных слов (например: оружие, убить, бомба).
   - **`vision_analyzer.py` (ПЗ 3, ПЗ 5, ПЗ 6):** 
     - Интегрирована `YOLOv8` для точного детектирования объектов (люди, машины и др.).
     - Подключена модель `ResNet50` (PyTorch) для классификации сцен кадра в целом.
     - Интегрирован `EasyOCR` для чтения вшитого в видео текста (титры, надписи).
   - **`llm_analyzer.py` (ПЗ 7):** Добавлен вызов **Gemini 1.5 Flash API**, который позволяет "посмотреть" на кадр глазами большой языковой модели и описать, происходит ли там что-то деструктивное или опасное (очень гибкий подход).

3. **Склейка и Постобработка (ПЗ 8):**
   - Написан `postprocessor.py`, который:
     - Делает **дедубликацию текста**, чтобы одно и то же слово, висящее на экране 10 секунд, не дублировалось в отчете 10 раз.
     - Осуществляет **склейку детекций YOLO**, объединяя разрозненные срабатывания по таймкодам в единый интервал (например: Человек присутствовал в кадре с 5.0 по 12.0 секунду).

4. **Оркестратор и Отчеты:**
   - Скрипт `main.py` собирает всё это воедино. Он скачивает видео, режет на кадры, извлекает звук, прогоняет через все нейросети и формирует два финальных отчета:
     - `results/report.json` - для дальнейшей программной работы.
     - `results/report.md` - красивый читаемый отчет.

5. **Инструкции (Курсовая):**
   - Создан подробнейший файл `README.md` прямо в папке с кодом. В нем пошагово расписано, как запустить скрипт локально, как отправить этот код на **GitHub** (для сдачи преподавателю) и как арендовать виртуальную машину на **Timeweb** и развернуть код там.

> [!TIP]
> Код написан с использованием ООП и разбит на файлы. Это очень ценится при сдаче курсовых проектов, так как показывает профессиональный подход в отличие от "лапши" в одном огромном файле.

## Ваши следующие шаги

1. Откройте файл `README.md` в папке `/home/kinet/Документы/Analyz_Data/`.
2. Получите API ключ от Gemini (ссылка есть в README).
3. Запустите пайплайн на каком-нибудь коротком тестовом видео, чтобы убедиться, что все работает на вашем ПК:
   ```bash
   python main.py --video "https://rutube.ru/shorts/6c48f15c9ad2a7a6250736b7375fe767" --is_url --fps 1
   ```
4. Следуя инструкции из `README.md`, выложите код на Github и разверните на сервере Timeweb.

Если при запуске будут не хватать каких-то библиотек, которые вы еще не ставили, используйте `pip install -r requirements.txt`. Удачи с курсовой!
